# 學測地科「十年命題舉證」網站

108 課綱學測自然考科地球科學試題命題舉證系統，涵蓋 106–115 學年度共 157 題，跨 22 個課綱節點、7 大主題。

## 內容

- **資料表**：157 題 × 10 學年度 × 22 個節點，每題標註年度、題號、節點、主題、概念摘要、認知層次、難度、是否含圖表、素養能力、來源、官方試題 PDF 連結。
- **網站架構**：
  - 星空 Hero + 統計數據
  - 課綱節點總覽（22 張卡片）
  - 年度 × 節點熱度矩陣（熱力圖）
  - 趨勢分析（認知層次堆疊條圖、圖表題/難題占比趨勢線圖）
  - 逐題舉證卡片（可搜尋與篩選）

## 檔案結構

```
index.html              主頁面
css/style.css           樣式（深色模式、響應式）
js/app.js               互動邏輯（篩選、搜尋、圖表）
data/questions.json     157 題完整結構化資料
data/curriculum_nodes.json   22 個課綱節點
data/questions_106_108.json
data/questions_109_112.json
data/questions_113_115.json
```

## 說明

節點歸屬、認知層次、難度、素養能力為教學端依 108 課綱回標的詮釋性分類，非大考中心官方分類。為尊重著作權，僅呈現概念摘要與命題證據，完整題文連結至官方試卷 PDF。
