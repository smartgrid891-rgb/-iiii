學測自然考科歷屆試題資料夾

下載日期：2026-08-23

說明：CEEC 沒有獨立的「地球科學」考科，地球科學是學測「自然考科」的一部分
      （物理／化學／生物／地球科學合在同一份試卷），故此地科相關內容
      透過自然考科全套下載取得。

內容：83～115 學年度學科能力測驗自然考科相關檔案，共 118 個檔案。
包含：
  - 試題內容（PDF / DOCX）— 歷屆試卷（含地科題目）
  - 選擇題答案 — 解答
  - 非選擇題評分原則 — 評分標準（111學年度起）
  - 答題卷（111學年度起）
  - 封面

檔名格式：<學年度>_自然_<類型>.<副檔名>
清單請見 manifest.csv。
